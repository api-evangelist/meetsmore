## Nittei Scheduler API

Self-hosted calendar and scheduler server. Rust (Axum, SQLx, PostgreSQL), MIT licensed,
version 0.44.0 released 2026-06-16. Forked from and built upon nettu-scheduler.

- [Repository and docs](https://github.com/meetsmore/nittei)
- Base path: `/api/v1` on your own deployment. The README's example host is
  `http://localhost:5000`; there is no hosted instance.
- OpenAPI: generated at runtime by utoipa and served by the instance at
  `/api-docs/openapi.json`, with Swagger UI at `/swagger-ui`. info.title "Nittei API".
- Auth: `x-api-key` header for server-to-server; RS256 JWT plus a `nittei-account` header
  for browser clients, with an allow/reject `schedulerPolicy` claim.
- Resources: Account, User, Calendar, CalendarEvent (iCalendar RRULE recurrence, exdates,
  reminders), Schedule, Service (bookable resources, booking slots), Status.
- Integrations: Google Calendar and Outlook Calendar, as busy-time sources or sync targets.
- Webhooks: reminder deliveries, verified by a static `nittei-scheduler-webhook-key` header.
- Errors: plain text/html bodies, NOT JSON and NOT RFC 9457. Key on the status code.
- No pagination, no rate limits, no Idempotency-Key, no request-id header.
- Client: `@meetsmore/nittei-client`, published to GitHub Packages (not public npm).

## use-ai Server

React client + Node/Bun server that lets an LLM drive a web application's own frontend.
BUSL-1.1 (source-available, not OSI open source), version 1.17.1 published 2026-08-04.

- [Repository and docs](https://github.com/meetsmore/use-ai)
- Packages: `@meetsmore-oss/use-ai-client`, `-core`, `-server`, `-plugin-workflows` on npm;
  container at `ghcr.io/meetsmore/use-ai-server` (unpinned `:latest`).
- Default port 8081. Transport is Socket.IO; the protocol is AG-UI, partially implemented.
- MCP: the server exposes browser-side tools to the model AS MCP tools, and federates
  remote MCP endpoints via `MCP_ENDPOINT_<NAME>_URL`. It is an MCP host and client — it is
  NOT an MCP server you can point an agent at.
- Honors the MCP `destructiveHint` annotation with an explicit user-approval gate.
